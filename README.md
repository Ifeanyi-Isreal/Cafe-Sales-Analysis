# Cafe-Sales-Analysis
This project focuses on analyzing café sales data to uncover key business insights and support data-driven decision-making. The dataset initially contained several data quality issues that affected its reliability for analysis.

To prepare the data for reporting, the cleaning process was carried out using Microsoft Excel for preliminary data validation and formatting, while Power Query in Power BI was used for advanced data transformation, including handling missing values, correcting inconsistent entries, standardizing data formats, removing duplicates, and creating calculated columns where necessary.

After transforming the dataset into a clean and analysis-ready format, an interactive dashboard was developed in Power BI to visualize sales performance, customer purchasing trends, product popularity, payment methods, and other key performance indicators (KPIs). The dashboard enables stakeholders to monitor business performance, identify trends, and make informed operational decisions.

#Problem Statement
The cafe generated sales records daily; however, the dataset suffered from several data quality issues that reduced its usefulness for business reporting and analysis. Inconsistent formatting, missing values, duplicate records, and inaccurate entries made it difficult to generate reliable insights or accurately measure business performance.

Without proper data cleaning and transformation, management would struggle to answer important business questions such as:
Which products generate the highest revenue?
Which payment methods are most frequently used?
What are the peak sales periods?
Which products are underperforming?
How do customer purchasing patterns change over time?

To solve these challenges, the dataset was cleaned, transformed, and modeled before developing an interactive Power BI dashboard that provides accurate, real-time business insights for decision-making.

#Data Quality Issues Identified
During data preparation, the following issues were identified and resolved:
Missing or blank values in key fields.
Duplicate transaction records.
Inconsistent date and time formats.
Incorrect or inconsistent product naming.
Invalid numerical values.
Inconsistent text capitalization and spacing.
Incorrect data types (text stored as numbers and vice versa).
Null values requiring replacement or removal.
Unnecessary columns that did not contribute to the analysis.
Data inconsistencies affecting aggregation and reporting.

#Objectives
The objectives of this project were to:
Clean and prepare raw café sales data for analysis.
Improve data quality by correcting inconsistencies and errors.
Transform the dataset into a structured analytical model.
Build an interactive Power BI dashboard.
Monitor sales performance through key performance indicators.
Identify customer purchasing patterns and product performance.
Support business decision-making through actionable insights.
